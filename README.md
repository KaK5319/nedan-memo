# 値段メモ

お店で撮った写真と一緒に、商品名・店名・値段を記録して「どの店が一番安いか」がひと目で分かるアプリです。
Web版プロトタイプの完成形を、Androidアプリにしたものです。

## できること

- 開くとお店の一覧（店名＋件数）。お店をタップすると、その店の商品が1行に3つ並ぶ棚ページへ
- 「店ごと／商品ごと」切り替え（開いた時は店ごと）。商品名で検索
- 商品の登録：写真＋商品名（登録済みの商品名チップから選べる）＋店名＋値段。日付は自動
- 同じ名前の商品が複数あってもよい。一番安い記録には赤いギザギザの「最安」シール
- 写真はお店の記録ごとに1枚ずつ（店ごとに別々の写真にできる）
- 写真タップで大きく表示、写真長押しで削除メニュー（その店の記録だけ／商品をすべて）
- お店カード長押しでお店の名前を変更（記録と紹介がついてくる）
- お店の紹介（営業時間・住所・電話番号・メモ）を書ける。電話番号タップで発信
- データは端末内に保存（JSONファイル）。最初は空っぽ

## ビルド

Codemagic の `Android APK` ワークフローでビルドします（このリポジトリを Codemagic に追加してください）。

- `flutter create` で Android プロジェクトを生成し、アプリ名を「値段メモ」に設定
- `icon/icons.b64`（最安シールのアイコン一式を base64 化したもの）を展開してランチャーアイコンに設定
- リリース APK をビルドして成果物として公開

アプリID: `com.example.nedan_memo`
